# YouPlanner — спецификация

Дата: 2026-09-10
Статус: утверждён

## 1. Цель

Одностраничный трекер привычек. Один HTML-файл (`YouPlanner.html`), CSS и JS внутри,
работает локально в браузере с `file://`. Данные — в `localStorage`. Только desktop,
минимальная ширина 1024px, адаптивность не требуется.

## 2. Расположение

- **Итоговый файл:** `проект/таблица привычек/YouPlanner.html`
- **Рабочая папка сборки:** `проект/таблица привычек/.build/` (создаётся и удаляется в процессе)
- Кодировка всех файлов — UTF-8. Комментарии в коде — на русском.

## 3. Ограничения

- Чистый HTML5 / CSS3 / ES2020. Никаких внешних библиотек, CDN, шрифтов, сборщиков.
- Никаких сетевых запросов. Работает офлайн.
- Идентификаторы блоков — стабильные `id`, используются субагентом «UI-логика» и QA.

## 4. Схема данных

Три ключа в `localStorage`.

### `youplanner.habits`
```js
[
  { id: 'h1', name: 'Фаджр', type: 'boolean', unit: '', goal: null },
  ...
]
```
- `id` — строка, уникальная. Для дефолтных привычек — `h1`…`h11`. Для новых —
  `'h' + Date.now().toString(36) + Math.random().toString(36).slice(2, 7)`.
- `type` — `'boolean' | 'number' | 'choice'`.
- `unit` — строка, подпись единицы измерения; для `boolean` всегда `''`.
- `goal` — число > 0 для `number`; `null` для `boolean` и `choice`.

### `youplanner.records`
```js
{ "2026-09-08": { "h1": true, "h6": 2, "h7": "да" } }
```
- Ключ верхнего уровня — дата в формате `YYYY-MM-DD` (локальная дата, без UTC-сдвига).
- Значение: `boolean` → `true | false`; `number` → неотрицательное число;
  `choice` → `'да' | 'нет' | 'частично' | 'отдых'`.
- Отсутствие пары `habitId` в объекте дня = «день не заполнен» для этой привычки.
- Удаление последнего значения дня удаляет и ключ даты.

### `youplanner.theme`
- Строка `'light'` или `'dark'`. По умолчанию (ключ отсутствует) — `'light'`.

## 6. Правила прогресса

Прогресс считается **дважды** для каждого периода: за неделю и за месяц.

**Знаменатель (база)** — число дней периода целиком. Дни без записи входят в базу
и дают вклад 0. Пустой период → 0%.

| type | вес дня | формула |
|------|---------|---------|
| boolean | `true` → 1, `false` → 0 | `Σ(вес) / база × 100` |
| choice | `да` → 1, `частично` → 0.5, `нет` → 0, `отдых` → 0 | `Σ(вес) / база × 100` |
| number | — | `(Σ(значение) / база) / goal × 100` |

- **Неделя:** база всегда 7. Одна галочка в понедельник = 14%. С каждым новым
  понедельником круг естественно обнуляется.
- **Месяц:** база — число прошедших дней месяца, с 1-го по сегодня включительно.
  3 галочки 10-го числа = 30%. Для месяца, который уже закончился, — все его дни;
  для месяца, который ещё не начался, — пустой период (0%).
- Прогресс не ограничен сверху: значение может быть > 100%.
- Итоговое число округляется до целого при выводе.
- Изменения в будних днях прошлой недели не влияют на недельный круг, но влияют
  на месячный — это ожидаемое поведение гибридной схемы.

## 7. Навигация по времени

- Таблица показывает одну неделю, колонки — понедельник…воскресенье.
- Кнопки `‹` и `›` листают недели на ±7 дней. Кнопка «Сегодня» возвращает к текущей неделе.
- **Месяц для месячного процента** определяется по дате **понедельника** отображаемой недели.
- Заголовок: месяц понедельника + диапазон недели. Пример: `Сентябрь 2026 · 7–13 сентября`.
- Если неделя пересекает границу месяца, диапазон показывается с обоими месяцами:
  `31 авг – 6 сент 2026`. Месячный процент при этом считается по месяцу понедельника (август).
- Даты в шапке таблицы — формат `ДД.ММ`.

## 9. Рендер ячеек

- **boolean:** `<input type="checkbox">` + кнопка `<button class="cell-x">✗</button>`.
  Состояния взаимно исключающие: клик по чекбоксу → `true` (галочка снимается → запись
  удаляется, состояние «пусто»); клик по `✗` → `false` (повторный клик → «пусто»).
- **number:** `<input type="number" min="0" step="1">`. Пустое поле → запись удаляется.
- **choice:** `<select>` с опциями: пусто / да / нет / частично / отдых. Выбор пустой
  опции → запись удаляется.
- Все интерактивные элементы несут `data-habit-id` и `data-date`.

## 10. Прогресс-круг

Гибридная схема: круг показывает неделю, месяц — второй строкой внутри круга.

- SVG 64×64px, радиус 27, круг-фон + дуга, `stroke-linecap="round"`.
- Дуга заполняется на `min(недельный_процент, 100)`% длины окружности.
- **Первая строка** — недельный процент, 14px, полужирный, цвет `--text`.
  Показывает реальное значение (может быть >100%).
- **Вторая строка** — месячный процент, 10px, цвет `--text-muted`, отступ ~2px
  от первой строки, формат `М: 30%`. Тоже реальное значение.
- Цвет дуги — акцентный (фиолетовый/синий), при `percent >= 100` — «успех».
- Обновление одной ячейки перерисовывает только круг своей строки.

## 11. Тема

- CSS-переменные на `:root` для светлой темы и `[data-theme="dark"]` для тёмной.
- Переключатель пишет в `youplanner.theme` и меняет `data-theme` на `<html>`.
- Переключение темы **не должно** перерисовывать таблицу или терять введённые значения.
- Контраст текста к фону — не ниже 4.5:1 в обеих темах.

## 12. Модальное окно

- Открытие: `#edit-habits-btn`; закрытие: `#modal-close`, клик по подложке, `Escape`.
- Список существующих привычек с кнопками управления; форма добавления новой.
- Редактируемые поля: `name`, `unit`, `goal`. `type` доступен для изменения **только
  если у привычки нет ни одной записи** в `youplanner.records`; иначе поле заблокировано.
- Удаление привычки удаляет её записи из всех дат `youplanner.records`.
- Валидация: `name` не пустой и не дублирует существующее имя (без учёта регистра);
  `goal` — целое > 0 при `type === 'number'`. Ошибки выводятся в `#form-error`.

## 13. Требуемые функции (§ карточки субагента 1)

```js
loadHabits()              // → Habit[]; при отсутствии ключа записывает и возвращает дефолты
saveHabits(habits)        // → void
loadRecords()             // → Record<string, Record<string, value>>
saveRecords(records)      // → void
getRecord(date, habitId)  // → value | undefined
setRecord(date, habitId, value)  // value === undefined|null|'' → удаление записи
removeHabit(id)           // → удаляет привычку и все её записи
calcProgress(habit, dates)       // dates: string[] (YYYY-MM-DD) → number (может быть > 100)
addHabit(habit)           // → Habit (с новым id)
updateHabit(id, patch)    // → Habit | null
```

## 15. Критерии готовности (QA)

1. В `localStorage` после первого запуска — 11 привычек.
2. Таблица рендерится быстрее 50 мс.
3. Изменение ячейки мгновенно обновляет круг своей строки без перерисовки таблицы.
4. Переключение темы сохраняется в `localStorage` и не теряет значения ячеек.
5. Удаление привычки с данными удаляет и её записи.
6. `goal = 0`/`null` не приводит к делению на ноль или `NaN` — прогресс 0%.
7. Пустые записи (нет `youplanner.records`) не ломают рендер — все круги показывают 0%.
8. Навигация по неделям корректно пересчитывает даты и круг (в т.ч. переход через месяц).
9. Одна галочка в понедельник даёт 14% по неделе — знаменатель недели всегда 7.
10. Месячный процент считается отдельно от недельного и растёт по мере заполнения
    дней месяца с 1-го числа.
11. Записи прошлой недели не влияют на недельный круг, но входят в месячный.
12. В консоли браузера нет ошибок и предупреждений при штатных сценариях.
13. Файл открывается по `file://` без сервера.

## 16. Вне области работ

- Мобильная и планшетная вёрстка, свайпы, тач-жесты.
- Синхронизация, экспорт/импорт, статистика по неделям и годам.
- Уведомления, таймеры, авторизация.
