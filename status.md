## Работает

- Главное: 12 привычек, режим День / Неделя, прогресс-круги.
- Каза: очередь каза-намазов, план на сегодня, ручное добавление пропуска,
  отмена последнего выполнения.
- Расписание: четыре типа дня (будний, выходной, ураза, физработа),
  переключатель и список времени с текстом; пока только чтение, выбранный тип
  не сохраняется. Вход из таб-бара и кнопки шапки на ПК.
- Молитвы: времена пяти намазов и восхода, первый запуск с координатами,
  метод расчёта и мазхаб в настройках, кольцо следующего намаза и счётчик.
- Ураза: счётчик каза-постов, «Возместить 1 день», «Добавить уразу»,
  «Изменить счётчик», история событий.
- Цикл сна: три поля (во сколько лёг, через сколько заснул, во сколько встать),
  расчёт циклов по 90 минут, список из шести циклов, рекомендуемый подсвечен,
  полоска времени, галочка «встану по рекомендации» с парой
  actualWake/sleepMin, история сна (по записи на день, день сохранения формы).
  Открывается из гамбургера на телефоне и строкой в Настройках на ПК;
  на телефоне строка погашена.
- Статистика: хаб из четырёх строк с цифрой (каза-намазы, сон, ураза,
  привычки) — все строки рабочие, погашенных нет, — у каждой категории свой
  период (Неделя / Месяц / Год / Всё время, по умолчанию Месяц, отметка
  устройства; выбор хранится в youplanner.stats.period как объект с пятью
  полями), категория «Каза-намазы»: сумма каза за период, средний темп,
  текущая серия, общий остаток, график по дням; категория «Привычки»: список
  двенадцати строк с процентом за период и карточка привычки — средний
  процент, текущая и лучшая серия, всего отметок, график по дням
  и сетка-календарь; категория «Ураза»:
  остаток, возмещено и добавлено за период, начало истории и график
  возмещений — меньше пяти событий показывают строку вместо графика,
  а незаведённый счётчик — «Счётчик не заведён». История уразы чистится
  от битых записей при чтении, из снимка сервера и из файла копии;
  категория «Сон»: средний отбой, средний подъём и средняя длительность
  по истории раздела «Цикл сна» (правило 18:00, подъём по фактическому
  подъёму), число записей за период и график по дням; истории нет вовсе —
  «Истории сна нет», записей нет за период — «За выбранный период записей
  нет».
- Статистика, вход: на телефоне — кнопка ☰ в шапке главной, выезжающая
  панель «Меню»: строка «Общая статистика» со стрелкой-аккордеоном
  и скрытыми под ней четырьмя категориями (каза-намазы, сон, ураза,
  привычки); всего шесть пунктов с «Циклом сна». На ПК — строка
  в Настройках, панели там нет вовсе.
  Строка «Статистика» в Настройках на телефоне погашена. «Назад» из хаба
  возвращает туда, откуда вошли.
- Настройки: редактирование привычек, статистика (на ПК), молитвы, экспорт
  и импорт данных, строка версии.
- Общее: синхронизация с Firebase с валидацией разделов из облака теми же
  правилами, что при импорте файла, три уровня защиты данных, автобэкап в
  отдельном корне `FIREBASE_BACKUPS_URL` (не во вложенном `/backups`), экспорт
  и импорт в файл, PWA на iPhone.
