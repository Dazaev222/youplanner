Настройка Claude Code для проекта

1. Установите VS Code: https://code.visualstudio.com/download
   В VS Code установите расширение Claude Code от Anthropic.
2. Создайте или выберите рабочую папку проекта. Перенесите все файлы архива в её корень.
3. Windows: запустите claude-ansar-local.bat.
   Mac: запустите claude-ansar-local.command. Если macOS блокирует запуск, нажмите правой кнопкой и выберите «Открыть».
   Node.js и Claude Code CLI установятся автоматически; доступ подключится без ввода кода и имени.
4. Сохраните папку .claude: в ней находятся настройки проекта. Файл личного доступа
   удалится автоматически после настройки. Остальные файлы установщика останутся:
   при желании удалите их сами.
5. Откройте рабочую папку в VS Code и запустите расширение Claude Code.
